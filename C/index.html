📋 店铺下单 — 产品需求说明（PRD）
一、文档信息

文档名称：店铺下单模块产品需求文档

适用端：C端用户APP

需求类型：功能迭代

二、模块概述

为用户提供从"发现店铺"到"完成预约"的完整闭环体验，支持项目选择、服务商指定、时间预约、在线支付全流程。

三、用户路径

主路径：

  • 店铺详情页 → 项目详情页 → 订单确认弹窗 → 支付成功

页面流转说明：

  • 店铺详情页：展示店铺基础信息（名称、评分、营业时间、标签、地址）、服务项目分类列表
  • 项目详情页：展示服务大图、价格区域（绿色渐变背景）、服务须知、服务商横向列表、立即预约按钮
  • 订单确认弹窗：底部弹窗形式，包含服务信息、服务商选择、调剂选项、时间选择、价格明细、支付方式、底部操作栏。仅从项目详情页【立即预约】入口触发；项目卡片【+】按原先设定处理，不触发订单确认弹窗
四、功能需求

4.1 订单确认弹窗

  • 弹窗形式：底部滑出弹窗（Sheet），占屏幕高度90%，圆角20px
  • 入口说明：订单确认弹窗仅由项目详情页【立即预约】触发；项目卡片【+】按原先设定处理，不进入订单确认弹窗
  • 服务信息卡片：项目图片、名称、原价/现价、店铺名称、服务时长
  • 服务商选择：展示商户项目上挂靠的服务商，没有则提示"暂无可用服务商"，展示头像、名字（可点击跳转精选作品页）、评分，默认选中第一个，单选
  • 调剂选项：复选框，默认勾选"是否接受委派服务商"。勾选后订单可被商家转单给其他技师；不勾选则仅限选定服务商接单
  • 服务时间：点击展开日期选择（横向滚动，今天/明天+未来5天）和时间网格（9:00-21:00，每格30分钟，展示可预约/已约满状态），单选
  • 订单备注：多行文本输入，最多200字，选填
  • 价格明细：项目金额、优惠金额（红色）、消费券（暂无可用）、实付款（大字号红色）
  • 支付方式：余额支付、微信支付（默认选中）、红包支付、支付宝支付，单选
  • 协议勾选：默认勾选"我已阅读并同意《下单须知》"
  • 底部操作栏：订单确认弹窗底部展示【找人付】+【立即支付】，【立即支付】保留"邀请助力"角标
五、交互规则

5.1 页面切换

  • 店铺页 → 项目详情页：右滑进入动画
  • 项目详情页 → 店铺页：左滑返回
  • 点击立即预约：从底部滑出订单确认弹窗，底部展示【找人付】+【立即支付】
  • 点击弹窗外区域/关闭按钮：弹窗下滑关闭

5.2 状态管理

  • 服务商选择：项目详情页和订单弹窗同步选中状态
  • 时间选择：日期和时间必须同时选择才视为有效
  • 支付方式：微信支付为默认选中
  • 协议勾选：未勾选时禁止提交订单，提示"请阅读并同意《下单须知》"

5.3 数据校验

  • 提交订单前校验：服务时间已选、协议已勾选
  • 校验不通过时：以Toast提示用户错误原因，展示时长3秒
    • 服务时间未选："请选择服务时间"
    • 协议未勾选："请阅读并同意《下单须知》"
六、异常与边界
  • 无挂靠服务商：项目详情页服务商区域显示"暂无可用服务商"，按钮置灰不可点击
  • 网络异常：提交订单时网络断开，保存订单选择草稿
